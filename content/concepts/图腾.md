# 图腾

法文：*totem*（借自北美奥吉布韦语 *ototeman*，"他是我的亲族"）。涂尔干社会学体系中连接社会组织与宗教信仰的核心概念；图腾制度是已知最基本的宗教形式。

## 概念定位

图腾指**氏族以某种动物、植物或非生物作为集体名字、标记与崇拜对象**的制度安排。它同时是：

| 层面 | 内容 |
|------|------|
| 社会层面 | 氏族的名字与标志；亲属制度的组织原则（同图腾者为亲属，不得通婚） |
| 宗教层面 | 神圣崇拜的核心对象；图腾宗教的基础单元 |
| 认知层面 | 宇宙分类的骨架（胞族=属，氏族=种）；范畴/类别观念的原始形式 |

## 图腾制度的结构

### 图腾的三重神圣对象

图腾制度涉及三类不同层次的神圣事物：

```text
最神圣
    │
    ▼  图腾标记（符号/图画/储灵珈刻纹）
    │     → 刻于储灵珈/nurtunja/waninga/身体/武器/房屋
    │     → 神圣性最高（禁忌最严格）
    │
    ▼  图腾动物或植物本身
    │     → 禁食、禁杀（部分条件下可例外，须仪式化处理）
    │     → 神圣性低于标记
    │
    ▼  氏族成员（人）
    │     → 分享图腾本性；双重存在（人 + 图腾动物）
    │
（划归该图腾的宇宙其他事物——亚图腾层级）
```

**核心命题：图腾表象 > 图腾实物**

图腾的神圣性不在于物质载体（动物本身），而在于附着其上的集体观念（图腾标记是氏族集体力量的象征符号）。

### 图腾的神圣物品体系

| 物品 | 性质 | 禁忌 |
|------|------|------|
| 储灵珈（churinga） | 刻有图腾标记的椭圆形石板/木板；阿兰达人最神圣物品 | 存于ertnatulunga（圣地）；女性/未成年人严禁接触 |
| nurtunja / waninga | 仪式聚会时竖立的图腾标杆/编织标志 | 仪式结束后毁弃 |
| 图腾动物/植物 | 氏族共同禁忌对象 | 禁食/禁杀（有条件例外） |

### 氏族成员与图腾的关系

```text
起源神话：氏族祖先是图腾动物
    ↓
氏族成员 = 人类 + 图腾动物的双重存在
    · 体内有图腾的血肉
    · 可与图腾动物相互转化（特殊情境）
    · 命运联结：图腾动物状态影响氏族成员

神圣物质：
    · 血液（最神圣）——大量用于仪式；涂抹储灵珈
    · 毛发——编织入仪式物品（nurtunja/waninga）
```

## 图腾宇宙论：图腾作为宇宙分类骨架

图腾制度不只是关于特定动物的信仰，而是覆盖整个宇宙的分类系统：

```text
社会结构          →     宇宙分类
胞族（两分）      →     属/纲（最高分类单位）
氏族（若干）      →     种（次级分类单位）
划归各氏族的事物  →     该图腾的"同种"（共享神圣本性）
```

**对立分类原则**（两胞族的对立延伸到宇宙）：白凤头鹦鹉/黑凤头鹦鹉；太阳/月亮；水/土；和平/好战。

**类别观念的社会起源**：这些分类体系证明，逻辑范畴中的"类别"观念（有明确框架、含等级从属关系）以社会群体为模型——唯有社会才存在等级与联结，物质世界只能提供模糊的相似感知，无法提供类别的逻辑框架。

### 亚图腾与图腾升格

```text
主图腾（氏族）
    └─ 划归的事物 → 具有潜在图腾性（亚图腾）
           └─ 亚氏族分化 → 亚图腾升格为正式图腾

阿兰达案例：
  斯宾塞/吉兰统计约60种图腾
  斯特莱罗统计多达442种图腾
  → 亚氏族无限分化的历史结果
```

## 图腾制度的三个层级

除氏族集体图腾外，图腾制度还延伸到个体和性别层面：

| 层级 | 所属群体 | 获得方式 | 与图腾关系 | 禁忌强度 |
|------|---------|---------|-----------|---------|
| 集体图腾 | 氏族全体 | 世代继承 | 血亲（氏族出自图腾祖先） | 中（有条件例外） |
| 性别图腾 | 全体男性/全体女性 | 集体归属 | 血统起源神话 + 个体命运联结 | 高 |
| 个体图腾 | 单个个体 | 主动获取（苦行/幻觉）或他授 | 朋友/保护者（非血亲）；命运联结 | 最高（无例外） |

## 图腾神圣性的社会机制（Step 3补充）

图腾标记何以神圣？第二卷第7章通过[[集体沸腾]]机制给出社会学解释：

```text
集体聚会 → 集体沸腾 → 情感凝附于图腾标记（在场符号）
    ↓
图腾标记 = 氏族集体力量（[[曼纳]]/图腾本原）的象征
    ↓
图腾 = 氏族旗帜（图腾标记之所以神圣 = 它代表了氏族本身）
    ↓
宗教崇拜的对象 = 社会本身
```
