# 神圣与世俗

法文：*sacré / profane*。涂尔干在[[宗教生活的基本形式]]中建立的宗教社会学核心分析框架；一切宗教现象的基本结构。

## 概念定位

神圣/世俗二分是涂尔干对宗教所做的最基本的结构性区分：不是对宗教内容的描述，而是揭示一切宗教现象共同具有的**形式结构**。

```text
一切宗教
    ↓ 共同具有
神圣（sacré）  ←禁忌→  世俗（profane）

核心主张：
  两者的差别不是程度差别，而是种类差别（异质性是绝对的）
  → 不存在从世俗"量变"为神圣的连续过渡
  → 转换必须是根本性的变态（成年礼="死亡与再生"）
```

## 核心特征

| 特征 | 内容 |
|------|------|
| **绝对异质性** | 神圣/世俗不是同一量度上的两端，而是两种截然不同的存在类型；不能用"程度更高"来描述神圣 |
| **相互排斥** | 两界不可混同；接触即污染（神圣事物被凡俗触碰→亵渎；凡俗事物被神圣力量侵袭→危险） |
| **禁忌隔离** | 禁忌（taboo）是维持两界分隔的制度机制；消极膜拜的核心就是禁忌体系 |
| **任何事物均可神圣化** | 神圣性不固定于特定物质：石头/树木/动物/人/空间/时间均可成为神圣 |
| **转换的仪式性** | 从世俗进入神圣须经过仪式（成年礼/宗教仪典）——这种转换是本质性的变化 |

## 与宗教定义的关系

```text
宗教定义（涂尔干）：
  与神圣事物有关的信仰与仪轨的统一体系
    ↓
信仰 → 表达神圣事物及其与世俗关系的表现/观念
仪轨 → 规定人面对神圣对象时的行为方式
教会 → 将信奉者结合为道德共同体

→ 神圣/世俗二分是宗教定义的**前提**，而不是结论
```

## 图腾制度中的神圣层级

第二卷展开了图腾制度内部的神圣性等级结构：

| 对象 | 神圣程度 | 禁忌强度 |
|------|---------|---------|
| 图腾标记（储灵珈/刻纹/符号） | 最高 | 最严格（女性/未成年人禁触） |
| 图腾动物/植物 | 高 | 禁食/禁杀（有条件例外） |
| 氏族成员（分享图腾本性） | 中 | 血液/毛发具有神圣性 |
| 划归该图腾的宇宙事物（亚图腾） | 潜在 | 部分保护；可升格 |

这一层级结构证明：神圣性不是均质的，而是有程度差异——但任何神圣事物都与世俗领域保持绝对隔离。

## 神圣性的社会起源

涂尔干的核心主张：神圣性不是来自超自然力量，而是来自社会——神圣事物是集体力量的象征。论证主要在第二卷第7章（[[集体沸腾]]机制）展开：

```text
集体聚会 → 集体沸腾（effervescence collective）
    ↓ 产生强烈集体情感（超越日常自我的体验）
情感凝附于在场的图腾标记（氏族的共同符号）
    ↓
图腾标记获得神圣性（= 社会力量的对象化）
    ↓
神圣/世俗二分的经验根源：
  · 世俗 = 分散期（日常狩猎/采集，平淡）
  · 神圣 = 集会期（彻夜仪式，极度亢奋）
    ↓
神圣/世俗二分 = 社会/个人二分的宗教形式
= 集体生活/个体生活的对比被宗教化
```

**结论**：神圣性的来源不是超自然实体，而是社会集体力量（[[曼纳]]/图腾本原）在符号载体（图腾标记）上的凝附。

## 神圣观念的模糊性

[[宗教生活的基本形式]]第三卷第5章（[[禳解仪式]]）揭示了神圣观念的内在张力：

```text
神圣事物分两极：
  洁净（sacré pur）：有益的神圣力——图腾本原/神明/英雄/守护者
  不洁（sacré impur）：邪恶的神圣力——死者灵魂/经血/亵渎的力量

两者：
  → 都与凡俗领域同样隔离（对凡人都是禁忌）
  → 都具有同样强的传染性
  → 因此：两者都是"神圣的"——洁净/不洁是同一类别的两个变体
```

**转化机制**：洁净↔不洁的转化反映集体情感状态的变化（信心/困境）：
- 死者灵魂（哀悼期=凶险） → 哀悼仪式 → 社会重建信心 → 灵魂变为善良庇护者
- 神圣动物被妄食 → 神圣力无序传染 → 凡人获得危险的神圣性

**结论**：神圣/世俗二分不是简单的双极对立，而是：
- 神圣内部分为有益/邪恶两极（对应社会的两种状态）
- 世俗处于两者之间，被双重排斥（既不能接触神圣力，也不能接触不洁力）
