# 曼纳（mana）/ 图腾本原

法文：*mana*（美拉尼西亚借词）；*principe totémique*（图腾本原）。涂尔干在[[宗教生活的基本形式]]第6-7章中建立的核心概念：**宗教力量最基本、最原始的形式**——匿名、非人格、弥漫的神圣力。

## 概念定位

图腾本原/曼纳是涂尔干对"宗教力"的最终定名：不是神，不是灵魂，不是个人意志，而是一种**匿名弥漫的力量**，它是图腾宗教乃至一切宗教的底层基础。

```text
宗教力的形态谱系：
  图腾本原（最原始、非人格）
      ↓ 个体化
  灵魂（第8章）
      ↓ 神话化/人格化
  精灵/祖先（第9章）
      ↓ 集体化/普及化
  部落大神（第9章）

→ 图腾本原是整个宗教体系的动力根源
```

## 核心特征

| 特征 | 内容 |
|------|------|
| **匿名性** | 无固定名字；非具体人格，非个别神明 |
| **弥漫性** | 同时存在于三重载体：图腾标记、图腾动物/植物、氏族成员 |
| **可传递性** | 通过接触（储灵珈/仪式/血液/毛发）传递；可强化或削弱 |
| **道德性** | 命令、禁止、惩罚；既令人崇敬（提升），也令人恐惧（危险） |
| **二元性** | 正面：赋予力量/治愈/保护；负面：触碰禁忌→生病/死亡 |

## 三重载体

```text
图腾本原的物质载体（由高到低）：

储灵珈/图腾标记（最高集中）
    → 图腾本原最密集；禁忌最严格；仪式效力最强

图腾动物/植物
    → 携带图腾本原；禁食禁杀（神圣保护）

氏族成员（血液/毛发最集中体现）
    → 分有图腾本原；血液用于仪式；毛发编入神圣物品
```

## 跨文化等价物

| 名称 | 文化 | 内容 |
|------|------|------|
| **曼纳**（mana） | 美拉尼西亚 | 附着于特定人/物的超自然力量；可增强、转移、削弱；具有曼纳者死后才受膜拜 |
| **瓦坎/Wakanda** | 苏（Sioux）族 | 以超乎寻常方式作用于人的一切事物；既是宇宙秩序也是个人力量 |
| **奥伦达**（orenda） | 易洛魁（Iroquois）族 | 万物具有的神圣动力；与自然力（风/雷）密切相关 |
| **图腾本原** | 澳洲图腾社会 | 三者的澳洲等价物；匿名、弥漫、可传递；最基本形式 |

四者的共同结构：匿名+弥漫+可传递+道德性。这种跨文化分布证明图腾本原是**宗教力量观念的普遍原始形式**。

## 力的观念历史谱系

```text
图腾本原（宗教力）
    ↓ 概念抽象化（去宗教外衣，保留结构）
哲学"力"的概念（实体/动力因/本体）
    ↓ 进一步去宗教化/实验化/量化
科学"力"的概念（物理力/因果律/能量）

意义：
  科学的力的观念根植于宗教的力的观念
  → 宗教和科学处理同一实在，只是表达方式不同
  → 实证科学并非与宗教的断裂，而是其精炼化和世俗化
```

## 曼纳与灵魂的关系

```text
图腾本原（氏族级别，匿名弥漫）
    ↓ 进入每个成员体内（个体化）
灵魂（个体级别，但仍是图腾本原的一份额）

推论：
  · 灵魂的神圣性来自图腾本原
  · 灵魂的永恒性（转生/不朽）表达的是氏族图腾本原的永恒性
  · 灵魂不死 = 图腾本原（= 社会力量）不死
```

## 曼纳的社会起源

```text
图腾本原从何而来？（第7章核心论证）
    ↓
集体沸腾（见[[集体沸腾]]）：
  氏族集体聚会 → 情感放大 → 超常体验
  → 个体感受到超越自身的力量
  → 力量客观化、凝附于图腾标记
    ↓
图腾本原 = 社会力量的对象化
→ 宗教力 = 道德力 = 社会强制力（命令/提升/约束个体）
```

## 与[[神圣与世俗]]的关系

神圣性（sacré）的实质就是图腾本原/曼纳的集中：

```text
曼纳/图腾本原（力量的存在）
    ↓ 凝附
神圣对象（图腾标记/储灵珈/图腾动物）
    ↓ 与之隔离
世俗领域（日常生活，无图腾本原渗透）

禁忌体系 = 维持图腾本原不被稀释/污染的制度机制
```
