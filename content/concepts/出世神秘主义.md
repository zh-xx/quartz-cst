# 出世神秘主义（außerweltliche Mystik）

## 概念定位

出世神秘主义是[[entities/persons/韦伯|韦伯]]比较宗教救赎类型学中的三个基本类型之一。它指的是通过**内心对世界的根本脱离**（而非外在行动证明或改造）来实现救赎的宗教取向。在韦伯的比较宗教社会学中，它是[[concepts/入世禁欲|入世禁欲]]（innerweltliche Askese）的结构对立极。

此概念在 READ-009（新教伦理）中作为"入世禁欲"的对照项被引出，在 READ-010（儒教与道教）中补充了第三种类型（"适应世界"），在 READ-012（印度的宗教）第二、三篇中全面展开为正向分析案例，在第三篇第六章上升到全亚洲比较终局的框架概念。

→ 三极完整类型学：**入世禁欲**（西方清教）→ 理性支配世界；**出世神秘主义**（印度）→ 内心逃离世界；**适应世界**（中国儒教）→ 审美维护世界

---

## 核心定义

出世神秘主义 = 救赎通过**内心对世界的根本脱离**来实现——不改造世界，也不适应世界，而是**从世界的内在意义中撤离**。

```text
出世神秘主义的操作逻辑：
  救赎目标（涅槃/梵天合一/jivanmukti）
    不是通过行动获得
    而是通过意识状态的转变获得
       ↓
  身在世间，心已离世
    → 外在行为可以继续（jivanmukti）
    → 但内心已从世界中根本脱离
    → 行动本身不产生伦理意义
```

---

## 与"入世禁欲"的结构对立

| 维度 | 入世禁欲（清教） | 出世神秘主义（印度教系） |
|------|----------------|----------------------|
| **救赎指向** | 通过行动证明恩宠状态 | 通过冥思体验达到脱离 |
| **对世界的态度** | 改造世界——做神的工具 | 逃离世界——从世界中解放 |
| **行动的伦理意义** | 行动本身即宗教义务（天职） | 行动是执着/渴望的表现；至多"无执着"行动 |
| **方法论方向** | 生活样式的理性系统化 | 精神状态的冥思技术系统化 |
| **伦理人格** | 产生——行动中确证的统一人格 | 消解——与宇宙/神合一中消融个体 |
| **经济伦理** | 致富=恩宠证明→理性资本主义精神 | 逃离经济利害→传统主义 |

## 印度路径中的展开（READ-012）

### 正统路径

```text
数论（Sāṃkhya）：
  精神（purusha）认识与物质（prakṛti）的根本区别
  → jivanmukti（生前解脱）：
    "知者"已知真实自我与业报机制无关
    → 行为发生，但无执着——"如莲花不着水"

吠檀多（Vedānta）：
  ātman = Brahman（个我即宇宙本体）
  → 世界 = māyā（幻象）
  → 认识此真理 = 解脱

薄伽梵歌（综合）：
  karma-yoga = 行动不执着结果
  → "履行自己的种姓义务"是可被接受的行动
  → 但不是为了改造世界，而是为了脱离业报
```

### 异端路径

```text
耆那教：
  积极禁欲 → 灭除业物质 → 灵魂解脱
  → 有"类清教"外在面貌（商业诚信、方法性生活规制）
  → 但礼仪隔离阻断社会融合——无法产生工业组织

原始佛教：
  最纯粹的出世神秘主义形态
  → 一切行动 = 渴望（tanhā）的表现
  → 救赎 = 灭渴望 = 涅槃（绝对寂灭）
  → "中道"：既不积极禁欲，也不肯定世界
  → 纯粹冥思→无任何经济伦理可能
```

### 在亚洲布教中的变形（第三篇）

```text
大乘佛教：
  菩萨理念 = 延缓涅槃以救度众生
  → 恩宠可超然于业报
  → 但救赎方向仍是"隐于俗世背后"：
    十地论最高阶段 = 入灭于"法云"（全智全能）

禅宗（日本）：
  漠视外在世界体验、漠视肉体
  → 武士阶级珍视为"锻炼坚定使命"的手段
  → 产生"轻视生命"的非理性效果

小乘佛教（东南亚）：
  僧院神权政治
  → 贬斥种姓义务 → 消灭职业忠诚的心理动机
  → 近代集约劳动须靠引入外来劳动力
```

## 全亚洲框架中的终局定位（第三篇第六章）

章6将出世神秘主义放入更广阔比较框架：

```text
亚洲救世论的共同逻辑：
  最高救赎 = 灵知（gnosis）——对世界/生命"意义"的神秘知识
  → 不是经验科学知识
  → "隐于俗世背后的国度"——不具理性形式
  → 被体验为"空"：跳脱现世及其一切造作

出世神秘主义的全亚洲心理学后果：
  安静（神圣境界）↔ 不安（被造物状态）
  → 对俗世及俗世造作的贬斥
  → 无法对行动赋予宗教意义
  → "面对世界与一己的行为而得确证，
     是不会在以上两种态度当中、也无法通过这两种态度来达到的。"
```

## 与"入世禁欲"+"适应世界"的三极类型

| | 入世禁欲 | 出世神秘主义 | 适应世界 |
|---|---|---|---|
| 典型 | 清教 | 印度教/佛教 | 儒教 |
| 对世界 | 理性支配 | 内心逃离 | 审美维护 |
| 文本来源 | READ-009 | READ-012 | READ-010 |
| 是否产生伦理张力 | 最高张力——改造世界 | 零张力——消解世界意义 | 最低张力——认同现有秩序 |
| 是否产生系统生活方法论 | 是 | 否 | 否（仅礼仪性体系化） |
| 经济后果 | 资本主义精神 | 传统主义 | 传统主义（俸禄利益强化） |

→ 比较页：待建"印度-vs-清教"比较页（Step 4/5）
