# 天职/职业（Beruf）

## 概念定位

天职/职业（德：Beruf；英：calling / vocation）是[[entities/persons/韦伯|韦伯]]在《新教伦理与资本主义精神》第一卷第三章通过语言学考证建立的核心概念。它不是一个既存术语，而是**一个词的诞生本身就是一次宗教-伦理革命的证据**。

概念在[[entities/texts/新教伦理与资本主义精神|新教伦理与资本主义精神]]第一卷第三章全章论述；是全书论证链的关键转折点。

## 语言学考证

韦伯的第一个论证是语言学的：

| 语言传统 | 是否有对应词 | 说明 |
|---------|-----------|------|
| 古希腊文 | 无 | 无将俗世劳动与神圣召唤合并的词 |
| 拉丁文（天主教） | 无 | opus（工作）与 vocatio（召唤）分离 |
| 古希伯来文 | 无 | 俗世劳动与神意的语义融合缺席 |
| 德文 Beruf（宗教改革后） | **有** | 路德翻译《圣经》时首次将"俗世职业劳动"与"神的召唤"融合为同一个词 |
| 英文 calling（宗教改革后） | **有** | 与 Beruf 等价；"被上帝召唤去做的职业" |

**关键节点**：路德翻译《旧约》（《便西拉书》）时，将原文中"坚守本分"的意思处理为 Beruf，这是该词在此意义上的发明时刻。词义史即思想史的直接证据。

## 路德的天职概念

路德引入 Beruf 的最初含义：

```text
传统天主教立场：
    俗世生活 = 道德上较低等（修道生活才是真正的宗教献身）
    职业劳动 = 为维持生存的世俗活动，与救赎无直接关联

                 ↓ 路德宗教改革

路德的天职命题：
    每个人在俗世的岗位（Beruf）= 神分配给他的位置
    履行俗世职业义务 = 在神面前被悦纳的唯一方式
    修道生活反而是逃避神意的自私行为
```

**路德版天职的特征**：
- 强调守本分：安于神所分配的位置，不主动改变职业
- 传统主义倾向：不鼓励超越性的自我改造
- 消极性：天职是义务，而非积极自我证明的场域

## 路德版的局限

韦伯着力指出路德版天职概念的局限，以引出第二卷向加尔文主义的转向：

| 维度 | 路德的天职 | 加尔文派/禁欲新教的天职（待写，第二卷） |
|------|---------|--------------------------------------|
| 对俗世的态度 | 顺从（神已安排，守本分） | 积极改造（通过劳动证明自己是选民） |
| 对职业变动的态度 | 消极，安于现状 | 可以、应该通过理性劳动扩展 |
| 与救赎的关系 | 间接（神意安排，非证明工具） | 直接（世俗成就=救赎确证的外部证明） |
| 对传统主义的关系 | 维持传统生活水准 | 克服传统主义，追求理性营利 |
| 资本主义精神亲和性 | 弱 | 强（第二卷核心论题） |

天职概念是从"经验问题"转向"历史因果解释"的枢纽：词的存在证明新教创造了一种前所未有的伦理意义结构，这是资本主义精神得以形成的前提。

## 与资本主义精神的关系

→ 详见 [[concepts/资本主义精神|资本主义精神]]

天职概念是资本主义精神的**伦理语义基础**：将职业劳动提升为宗教义务，是将营利活动"去传统化"的必要条件。但路德版天职本身尚不足以产生积极的入世禁欲——这一转化需要加尔文派的神学结构（预定论+救赎焦虑+入世证明机制）。
