# 业报与轮回（Karma & Samsāra）

## 概念定位

业报（Karma）与轮回（Samsāra）是[[entities/persons/韦伯|韦伯]]在《印度的宗教》中认定的印度教唯一两条"教条性的"（dogmatisch）教义。在韦伯的比较宗教社会学中，这两条教义的结合——特别是它们与[[concepts/种姓|种姓]]秩序的联结——产生了**历史上最彻底的神义论**。

单独建页理由：两条教义在全书中高度配对使用，不可拆分分析；合并建页避免两条短页互相交叉引用。

---

## 核心定义

| 概念 | 定义 | 与种姓的结合点 |
|------|------|--------------|
| **业报（Karma）** | 所有行为的伦理因果绝无消失；善行/恶行决定再生时的命运 | 当前种姓地位 = 前世业报的"应得"结果——非偶然，是宇宙道德秩序的体现 |
| **轮回（Samsāra）** | 灵魂在生死中无尽循环，经历各种形态的再生 | 轮回的具体形态（种姓等级）= 前世业报的反映 |

```text
业报 + 轮回 + 种姓秩序

  → 个人当前处境 ← 前世行为的自然结果
  → 社会不平等 ← 宇宙道德秩序的体现（非人为压迫）
  → 改善此世地位的手段 ← 履行种姓义务、积累正业、期待更好的再生
  → 革命/改革 ← 被神义论完全封堵（此世秩序是"应得的"）
```

## 作为"最彻底的神义论"

韦伯的判定（第一篇第十二章）：

> 业报神义论是**历史上曾出现过的最彻底的一种神义论**——它以完全合理化的宇宙道德秩序来解释现实中所有的不平等，将整个社会结构嵌入一个宗教上自洽的永恒轮回之中。

**与其他神义论形态的比较**：

| 神义论类型 | 文本来源 | 核心机制 | 与业报神义论的差异 |
|-----------|---------|---------|-----------------|
| 基督教苦难神义论 | — | 受苦 = 神的试炼/计划的一部分 | 人格神；受苦有意义无因果对应 |
| 犹太教灾祸神义论 | READ-011 [[concepts/世界紧张性\|世界紧张性]] | 神本身降灾祸——因以色列违约 | 人格神主动行动；灾祸=惩罚→改过可能；产生世界紧张性 |
| 儒教秩序适应 | READ-010 | 此世秩序本身是和谐的；无超越性批判立足点 | 无需神义论——根本不产生"恶/苦难为何存在"的问题 |
| **业报神义论**（印度教） | READ-012（本书） | 一切处境=前世行为的精确报应；无需人格神来解释；纯因果—道德法则 | **最彻底**——完全非人格化、完全合理化、完全不提供"不公"概念的空间 |

## 全书三篇中的展开

### 第一篇（章12）：与传统主义的锁扣

```text
业报 + 种姓 → 传统主义推到极致

机制：
  职业变更 → 礼仪降格贬等风险
  + 业报伦理 → "履行自己的（种姓）义务"= 最高救赎手段
  → 经济理性主义无法从内部突破
```

**与基督教/儒教职业观的对照**：

| | 基督教（加尔文） | 儒教 | 印度教（业报） |
|---|---|---|---|
| 固守职业的理由 | 天职义务（证明恩宠状态） | 礼/修身/秩序理性主义 | 种姓义务 + 更好的再生许诺 |
| 激励结构 | 他世救赎（选民证明） | 此世和谐适应 | 来世更好的再生 |

### 第二篇（章7–9）：一切救赎论都是对业报的应对

```text
数论：认识精神与物质的根本区别 → 知者=非行者 → 不积业
吠檀多：认识ātman = Brahman → 个体消解 → 不再轮回
薄伽梵歌：karma-yoga → 行动不执着结果 → 不产生新业
耆那教：苦行+知识 → 灭业 → 灵魂解脱
原始佛教：灭渴望(tanhā) → 停止业的生产 → 涅槃
```

所有救赎论——无论正统还是异端——都以"如何逃脱业报机制"为其核心问题设置。

### 第三篇（章1、3、5、6）：业报在历史发展中的延续与突破

```text
大乘佛教（章3）：
  菩萨恩宠 → 可超然于业报因果的"钢铁力量"之外
  → 这是对业报机制的突破尝试
  → 但轮回与业仍是宇宙框架的不言自明前提

印度教复兴（章5）：
  毗湿奴教 → 信爱的恩宠可抵消业报
  摩陀婆派 → "个我是永恒且无可逆转的"——偏离正统业报论
  但整体而言：没有任何教派从根本上动摇轮回—业报前提

全亚洲终局（章6）：
  轮回与业 → 全亚洲对"俗世生活的合理意义"的普遍解释
  → 赋予在救世论上被贬斥的现实世界"相对而言合理的意义"
  → 是"全亚洲普遍取得支配性地位的解释"
```
