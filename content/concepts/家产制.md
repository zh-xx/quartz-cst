# 家产制（Patrimonialismus）

## 概念定位

家产制是[[entities/persons/韦伯|韦伯]]支配类型学（Herrschaftssoziologie）中**传统型支配**（Traditionale Herrschaft）的一个亚类型，也是《儒教与道教》（READ-010）第一至四章分析中国国家结构的**核心框架概念**。

它的基本含义是：支配关系以家族性、个人性的忠诚-服从关系为基础，而非以非人格化的、形式理性的规则和职责为基础。家产制官僚依赖与主君的个人关系维持地位，而非依靠明确界定的职责。

概念首次出现于 [[社会科学方法论文集]]（READ-008）"正当支配三类型"文；在 [[entities/texts/儒教与道教|儒教与道教]]（READ-010）章1–4中成为分析中国国家结构的轴心概念。

---

## 支配类型中的位置

```text
韦伯支配三类型：
    ① 合法型（Legale Herrschaft）
       基础：形式理性规则；官员服从法律；职责与人格分离
       典型：现代官僚制国家
           ↕ 对立
    ② 传统型（Traditionale Herrschaft）
       基础：神圣惯例；对主君（Herr）个人的传统性忠诚
       亚类型：
           家长制（Patriarchalismus）：小规模；家长亲自管理
           家产制（Patrimonialismus）：规模扩大；通过私人家臣/代理人管理
           苏丹制（Sultanism）：家产制极端化；主君个人意志完全凌驾传统
           ↕ 对立
    ③ 卡理斯玛型（Charismatische Herrschaft）
       基础：对领袖个人超凡魅力的情感折服
       典型：宗教先知、革命领袖

家产制 = 传统型支配 + 规模扩大 + 个人化行政班子
```

## 家产制的核心特征

| 特征 | 内容 | 与合法型官僚制的对比 |
|------|------|-----------------|
| 官职来源 | 主君恩赐；依附个人关系 | 依法任命；职责由规则规定 |
| 行政依据 | 主君意志 + 传统习惯（两者常矛盾） | 抽象法律规则 |
| 官员收入 | 俸禄（Pfründe）：从职位中抽取的非正式收益 | 固定薪资；公私财政分离 |
| 行政边界 | 无明确职责划分；职能可互换 | 明确的职责分工 |
| 对改革的态度 | 维护俸禄利益 → 系统抵制理性化 | 依规则实施；与个人利益分离 |
| 法律特征 | 卡地裁判（个案公正感） | 形式理性法（可计算性） |

## 家产制在中国的展开（《儒教与道教》章1–4）

### 家产官僚制的双重逻辑

```text
家产制官僚的处境：
    从君主恩赐中获得任命
        ↓
    收入来源：俸禄（手续费/摊牌/非正式收益）
        ↓
    任何理性化/法典化都直接威胁俸禄利益
        ↓
    官员阶层 = 系统性改革阻力
        ↓
    货币经济发展 + 俸禄结构 = 传统主义强化（非弱化！）
```

**悖论**：中国货币经济的扩展，非但没有推动理性资本主义，反而被俸禄国家体系吸收，成为传统主义的强化机制。

### 家产制国家的法律后果

```text
家产制 → 无独立法律职业（无形式法律推理体系）
    ↓
卡地裁判（Kadi-Justiz）：
    → 依个案公正感判决，不引具体法律
    → 不可计算性（Unberechenbarkeit）
    → 理性资本主义所需的"法律保障"缺失
```

### 家产制国家的行政后果

```text
家产制 → 无职责-人格分离
    ↓
官员外派到陌生地区（防止形成地方封建势力）
    + 俸禄收益依赖地方默许
    → 非正式掠夺性行政（而非依规则的行政）
    → 政治（掠夺）资本主义 = 财富积累的主要路径
```

## 家产制 vs. 封建制度：韦伯章2的核心比较

| 比较维度 | 中国（家产制） | 西方中世纪（封建制） |
|---------|------------|----------------|
| 正当性基础 | 卡理斯玛 + 传统；主君个人权威 | 封建契约（封君-封臣的人格性义务） |
| 权力分布 | 高度集权于皇帝；官员无独立封建地位 | 分权；封建诸侯有独立地位与军事力量 |
| 收入形式 | 俸禄（Pfründe）：手续费/非正式收益 | 采邑地租；军事义务 |
| 对法典化 | 反对（阻碍俸禄利益） | 逐渐形成习惯法与成文法 |
| 对权利观念 | 无（服从传统/主君意志） | 封建权利/义务体系→孕育权利观念 |
| 历史后果 | 传统主义固化 | 领主与市民的博弈→城市自治→商业法 |
