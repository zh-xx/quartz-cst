# 教派 vs. 教会（Sekte vs. Kirche）

## 比较定位

这是韦伯宗教组织社会学的基础对子，建立于《新教伦理与资本主义精神》第二部。两者均为**理想类型**，核心分析价值在于**区分本身**所揭示的东西：不同的组织原则如何产生截然不同的伦理选拔与执行效果，从而影响成员的经济行为。

**核心问题**：宗教组织的结构原则如何决定成员的伦理资质与商业信用？

## 核心对比

| 维度 | 教会（Kirche） | 教派（Sekte） |
|------|--------------|-------------|
| 性质 | 恩宠机构（Gnadenanstalt） | 自愿性宗教-伦理资质共同体 |
| 成员资格来源 | 出生赋予（受洗即成员） | 通过调查后**投票**准入 |
| 恩宠授与对象 | 义人与不义人（普遍性恩宠） | 仅授予经证明的适格者 |
| 成员品质保证 | 无（生来属于，无选拔机制） | 有（持续证明；过失即逐出） |
| 被逐出的后果 | 宗教意义 | 宗教 + 商业信用 + 社会地位三重崩塌 |
| 纪律主体 | 圣职者（官职型权威） | 平信徒主导 |
| 惩戒方式 | 权威惩戒个别具体行为 | 培育并拣选整体伦理资质 |
| 成员资格的经济含义 | 无信用保证 | = 伦理资质证书；等价于商业信用担保 |

```text
教会原则（Kirchenprinzip）：
    制度性恩宠 → 圣礼有效性与教士官职绑定
    任何受洗者均是成员 → 无伦理选拔
    → 成员资格 ≠ 伦理资质证书

            ↕ 对立原则

教派原则（Sektenprinzip）：
    个人卡理斯玛资质 → 须经同侪审查确认
    唯有通过品行调查并经投票者才可入会
    → 成员资格 = 经同侪证明的伦理资质证书
```

## 教派侧的机制展开

教会侧无选拔机制，无需展开。教派的分析价值来自其运作机制：

### 准入机制

```text
申请入会
    ↓
品行调查（追溯幼年；涵盖：违法？上酒馆？跳舞？看戏？打牌？不准时付账？轻浮？）
    ↓
教团成员投票
    ↓
准入 → 成员资格 = 绅士伦理资质的绝对保证
拒绝 → 无入会资格（不公开，但同侪知晓）
```

### 持续执行机制

> "再也没有任何陶冶手段比在弟兄伙伴圈子里维持社会性自尊自重之必要更为强大。"

```text
成为教派成员
    ↓
在弟兄圈子里须维持社会性的自尊自重（Selbstachtung）
    ↓
行为失格 → 同侪施压 → 不改正则被逐出
    ↓
被逐出 = 公开宣告此人伦理资质不合格
    = 商业信用丧失 + 社会地位降格
```

机制性质：不是威权惩戒（禁止特定行为），而是通过**社会性自尊自重的内化压力**持续选拔与培育整体伦理人格。

## 经验证据：1904年美国观察

韦伯以亲身观察为经验证据，显示这对区分在现实中的运作：

**北卡罗莱纳浸礼场景**：一个青年在冰冷水塘受浸。旁观者解释："他想在M.开家银行。"洗礼派准入须通过最严格的品行调查，通过后汇集整个地区的储金，信用无限大，无人可及。

**可携带性**：成员迁居他处携带教团证书，在任何地方向同教派弟兄取得信用——构成跨地域的伦理认证网络。

## 第三项比较：教派 vs. 行会

韦伯将教派与中世纪行会进一步对比，揭示教派产生资本主义精神的独特性：

| 比较维度 | 行会（Zunft） | 禁欲教派 |
|---------|------------|---------|
| 统合对象 | 相同职业的竞争者 | 经伦理筛选的信仰伙伴 |
| 对竞争的态度 | 限制竞争（Nahrungspolitik/生计政策） | 无反竞争目的 |
| 对成员资本主义成就的态度 | 警惕、排斥（成就瓦解行会精神） | 欢迎（成就=恩宠的自我证明） |
| 产生的经济伦理 | 传统主义（守成、限制扩张） | 理性营利的资本主义精神 |

行会成员的资本主义成就**瓦解**行会精神；教派弟兄的资本主义成就**强化**教派声望。这是为何行会产生不了近代市民资本主义精神——唯独禁欲教派的生活方法论能使资本主义个人主义的动力获得正当性。

## 世俗化：机制的延续

宗教动机消退后，教派机制以世俗形式延续：

```text
禁欲教派（17–18世纪）
    ↓ 世俗化
共济会 / 希腊字母社团 / 商业俱乐部 / 市民协会（19–20世纪）
    ↓ 机制结构完全相同
  投票准入 + 品行调查 + 伦理证明书 + 违规逐出
    ↓
扣眼上的徽章 = 世俗化的教派成员证书
```

世俗化 = 宗教动机被世俗身份认同动机替换；功能结构不变。
