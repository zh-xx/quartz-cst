# 行动与思辨——社会研究的基本预设与理论分歧

## 问题来源

[[宗教生活的基本形式]]结论第一点：**膜拜的首要性**——宗教的主要功能不是思辨（解释世界），而是行动（使人生活下去）。仪式是信仰的生产手段，而非信仰的产物。

这一命题揭示了一个比宗教研究更普遍的社会研究预设：**行动与思辨，哪一个在社会生活中具有本体论优先性？**

---

## 核心问题

| 层次  | 问题                                         |
| --- | ------------------------------------------ |
| 本体论 | 人与社会的基本关系是认知性的（人首先是观察/思考者）还是实践性的（人首先是行动者）？ |
| 因果论 | 观念驱动实践，还是实践产生观念？社会变迁从哪里开始？                 |
| 方法论 | 社会研究应优先研究什么——意识/信仰/意识形态，还是制度/行为/实践结构？      |
| 政治论 | 社会改良靠启蒙观念还是靠改变制度实践？                        |

---

## 理论立场图谱

```text
思辨在先（观念→实践）              行动在先（实践→观念）
        │                                   │
  启蒙主义路线                        涂尔干、马克思、布迪厄
  观念史研究                          韦伯（复杂中间立场）
  意识形态批判（部分）
        │                                   │
        └──────────────┬────────────────────┘
                       ↓
         这是社会理论史最核心的分歧之一
```

## 各理论家立场（随阅读推进填入）

### 涂尔干（已建立）

**立场**：行动在先

#### 四层回答

| 层次 | 涂尔干的立场 | 关键证据 |
|------|------------|---------|
| **本体论** | 人首先是实践者/参与者，不是观察者——个体通过参与集体实践才得以成为社会存在 | 仪式聚集先于信仰形成；个体在集体实践中才真正感受到超越自我的社会力量 |
| **因果论** | 实践产生观念——信仰是仪式的产物，不是仪式的前提 | 膜拜首要性命题：宗教"使人生活下去"先于"解释世界"；集体沸腾→神圣性/信仰 |
| **方法论** | 研究实践/制度，不研究意识/信仰本身——以可观察的外部实践为入口 | 以法律体量研究团结（不问人的想法）；以自杀率研究整合（不问人的动机）；以仪式研究集体信仰（不问神学内容） |
| **政治论** | 社会改良靠改变制度实践，不靠启蒙观念——道德重建须先重建实践结构 | [[社会分工论]]结论：失范无法靠宣传新道德解决，须先重建[[职业团体]]；观念从新实践中自然生长 |

#### 跨书论证链：行动先于观念的五个案例

```text
社会分工论（1893）
    劳动分工（物质实践的变化）
        ↓ 产生
    有机团结 + 集体意识内容变化（个人尊严）
    → 不是观念先变，而是分工实践先变，观念随后调整

社会学方法的准则（1895）
    社会事实的外在强制性：规范/制度先于个人存在
        ↓
    个人是在已存在的实践框架中被塑造的
    → 不是个人观念构建制度，而是制度塑造个人观念

自杀论（1897）
    统计稳定性：无论个人有怎样的想法，社会整合程度决定自杀率
        ↓
    集体倾向（社会实践结构）> 个体意识（主观动机）
    → 研究实践结构，不研究个人心理

职业伦理与公民道德（遗著）
    职业团体缺位（实践结构空白）→ 失范（道德缺失）
        ↓
    不是"人们缺乏好的道德观念"，而是"承载道德的实践结构不存在"
    → 重建方案是制度，不是教育

宗教生活的基本形式（1912）：最直接的证明
    仪式聚集（共同实践）
        ↓
    集体沸腾（情感涌现）
        ↓
    神圣性/图腾信仰/集体意识（观念产生）
    → 信仰是仪式的产物；膜拜先于信仰，不是信仰先于膜拜
```

#### 与"思辨在先"的直接对照

| | 思辨在先（启蒙主义路线） | 涂尔干（行动在先） |
|-|----------------------|-----------------|
| 社会变迁的杠杆 | 启蒙新观念 → 推动新实践 | 改变制度实践 → 观念随之生长 |
| 道德危机的解法 | 传播更好的道德观 | 重建职业团体等实践载体 |
| 宗教的本质 | 对世界的错误解释（原始科学） | 集体实践产生的真实集体力量 |
| 研究方法 | 分析意识形态/信仰体系 | 观察制度/实践/仪式的外部形态 |
| 社会科学的任务 | 揭示错误观念，提供正确理论 | 描述社会实践结构，揭示其功能与原因 |

#### 方法论后果（完整版）

"行动在先"的预设直接决定了涂尔干选择什么作为研究入口：

```text
不研究                          而研究
  ↓                               ↓
人们相信什么（信仰内容）  →  人们做什么（法律/仪式/统计行为）
人们为何自杀（主观动机）  →  自杀率如何随社会结构变化
宗教的神学内容            →  仪式的形式与功能
人们的道德观念            →  法律制度与职业团体的结构
```

这套方法论的一致性贯穿全书：涂尔干从未用问卷询问人们的想法，始终以**可观察的外部实践形态**为研究材料。

**关键文本**：[[宗教生活的基本形式]]结论（膜拜首要性）；[[社会分工论]]第一版序言 + 结论（职业团体方案）；[[自杀论]]第三编（集体倾向的社会实在性）；[[职业伦理与公民道德]]全书

### 韦伯（待填入）

**预设立场**：复杂中间立场

**预设方向**：韦伯以"社会行动"（soziales Handeln）为社会学基本单位，但他认为社会学必须理解行动背后的**意义**（Sinn）——这使他同时关注行动和意义/观念。

**待追问的核心问题**：
- 韦伯的四类社会行动（工具理性/价值理性/情感性/传统性）如何处理行动与观念的关系？
- 《新教伦理与资本主义精神》：宗教观念（新教禁欲伦理）→ 推动资本主义实践——这是否是对"行动在先"的反驳？
- 韦伯的"理解社会学"（Verstehen）：要理解行动，必须理解行动者的主观意义——这是否把"思辨"重新带回社会学中心？
- 与涂尔干的根本分歧：个体行动的主观意义 vs. 集体实践的客观功能，哪个是社会学的基本单位？

### 布迪厄（待填入）

**预设立场**：行动在先（实践理论）

**预设方向**：布迪厄的实践理论（Theory of Practice）明确批判既把社会学还原为客观结构（结构主义）又还原为主观意识（现象学）的做法——他提出"惯习"（habitus）作为实践感，是身体化的、前反思的行动倾向。

**待追问的核心问题**：
- 惯习（habitus）：行动者的实践感是身体化的、非意识的——这与涂尔干的集体沸腾产生信仰有何结构相似性？
- 场域（champ）：实践发生的结构性空间——这是否是涂尔干"社会类型"的延伸？
- 布迪厄对涂尔干的继承与批判：在哪些点上布迪厄明确接续涂尔干，在哪些点上他修正了涂尔干？
- 符号暴力（violence symbolique）：观念/分类本身成为支配工具——这如何处理行动/思辨的关系？

## 当前可建立的分析框架

```text
行动/思辨之分 → 决定三个研究选择：

①  研究对象：
    思辨在先 → 研究意识/观念/信仰/意识形态
    行动在先 → 研究制度/实践/仪式/行为

②  因果方向：
    思辨在先 → 新观念推动新实践（启蒙路线）
    行动在先 → 新实践产生新观念（制度路线）

③  社会变迁：
    思辨在先 → 教育/传播/批判意识是变迁杠杆
    行动在先 → 制度设计/结构改造是变迁杠杆
```

涂尔干已经在第三个选择上给出了最清晰的答案：失范无法靠宣传新道德解决，必须先建立职业团体这样的制度实践。
